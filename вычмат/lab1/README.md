# Лабораторная работа №1 — Решение СЛАУ

## Постановка задачи

1. № варианта определяется как номер в списке группы согласно ИСУ.
2. Выбор языка программирования зависит от преподавателя‑практика.
3. Численный метод должен быть реализован как отдельная подпрограмма/метод/класс. Все входные и выходные данные передаются параметрами.
4. Размерность матрицы: **n ≤ 20** (задаётся из файла или с клавиатуры — выбор пользователя).
5. Должен быть реализован ввод коэффициентов матрицы **и** с клавиатуры, **и** из файла (выбор пользователя).

---

## Требования к реализации

### Прямые методы

- Вычисление определителя **по треугольной матрице**.
- Вывод треугольной матрицы (включая преобразованный столбец **B**).
- Вывод вектора неизвестных: \(x_1, x_2, \dots, x_n\).
- Вывод вектора невязок: \(r_1, r_2, \dots, r_n\).
- С использованием готовых библиотек найти решение задачи и определитель, **сравнить** с результатами вашей реализации и **объяснить** сходство/различия (это объяснение должно быть в отчёте).

### Итерационные методы

- Точность задаётся с клавиатуры/файла.
- Проверка диагонального преобладания. Если его нет — делать перестановку строк/столбцов, пока преобладание не будет достигнуто. Если добиться невозможно — выводить соответствующее сообщение.
- Вывод **нормы матрицы** (любой нормы на ваш выбор).
- Вывод вектора неизвестных: \(x_1, x_2, \dots, x_n\).
- Вывод числа итераций, за которое найдено решение.
- Вывод вектора погрешностей: \(|x_i^{(k)} - x_i^{(k-1)}|\).

## Содержание отчёта

- Цель работы
- Описание метода, расчётные формулы
- Листинг программы (минимум — там, где реализован сам метод)
- Примеры и результаты работы программы
- Выводы

Отчёт предоставляется в электронном/бумажном виде.

6. Идея метода Гаусса с выбором главного элемента по столбцам/строкам.
7. Что такое сходимость итерационного метода?

10. Идея метода Гаусса‑Зейделя.
11. В каких случаях применяется метод Гаусса с выбором главного элемента?

13. Критерии окончания итерационного процесса метода простой итерации.
