Для решения нелинейного уравнения `cos(x) - x = 0` методом половинного деления (бисекции) выполним следующие шаги:

1.  **Определение функции:**
    Пусть `f(x) = cos(x) - x`.

2.  **Проверка наличия и количества корней на интервале:**
    Метод половинного деления гарантирует нахождение одного корня, если функция `f(x)` непрерывна на интервале `[a, b]` и `f(a) * f(b) < 0`. Если `f(a) * f(b) > 0`, это означает, что на интервале либо нет корней, либо их четное количество. Если `f(a) * f(b) = 0`, то один из концов интервала является корнем.

    Чтобы достоверно проверить наличие *нескольких* корней или их отсутствие, особенно в случае `f(a) * f(b) > 0`, необходимо проанализировать производную функции.
    *   `f(x) = cos(x) - x`
    *   `f'(x) = -sin(x) - 1`
    Поскольку `-1 <= sin(x) <= 1`, то `-1 <= -sin(x) <= 1`.
    Следовательно, `-1 - 1 <= -sin(x) - 1 <= 1 - 1`, что означает `-2 <= f'(x) <= 0`.
    Производная `f'(x)` всегда отрицательна или равна нулю (в точках, где `sin(x) = -1`). Это означает, что функция `f(x)` является монотонно убывающей (или невозрастающей) на всей числовой оси.
    **Вывод:** Монотонно убывающая функция может иметь **не более одного корня**.
    Таким образом, если `f(a) * f(b) < 0`, то на интервале `[a, b]` существует **ровно один корень**.
    Если `f(a) * f(b) > 0`, то на интервале `[a, b]` **нет корней**.
    Если `f(a) * f(b) = 0`, то один из концов интервала является корнем.

3.  **Достаточное условие сходимости метода:**
    Для метода половинного деления достаточное условие сходимости:
    *   Функция `f(x)` непрерывна на интервале `[a, b]`. (Наше `f(x)` непрерывно как разность непрерывных функций `cos(x)` и `x`).
    *   `f(a) * f(b) < 0`. (Это условие будет проверено перед началом итераций).
    При соблюдении этих условий метод бисекции гарантированно сходится к единственному корню.

### Реализация на Python

```python
import math

def f(x):
    """
    Определяемая функция: cos(x) - x
    """
    return math.cos(x) - x

def bisection_method(a, b, tol):
    """
    Решает уравнение f(x) = 0 методом половинного деления.

    :param a: Левая граница интервала
    :param b: Правая граница интервала
    :param tol: Допустимая погрешность вычисления
    :return: Кортеж (найденный корень, значение функции в корне, количество итераций)
             или None, если корень не найден или условий не выполнено.
    """
    print(f"Начальный интервал: [{a}, {b}]")

    f_a = f(a)
    f_b = f(b)

    # Проверка наличия и количества корней
    # (Используем знание о монотонности f(x) = cos(x) - x)
    if f_a == 0:
        return a, f_a, 0
    if f_b == 0:
        return b, f_b, 0
    
    if f_a * f_b > 0:
        print("-------------------------------------------------------------------------------------------------------------------------------------------------")
        print(f"f({a}) = {f_a}, f({b}) = {f_b}")
        print("Значения функции на концах интервала имеют одинаковый знак (f(a)*f(b) > 0).")
        print("Поскольку функция f(x) = cos(x) - x является монотонно убывающей, на данном интервале корней нет.")
        print("-------------------------------------------------------------------------------------------------------------------------------------------------")
        return None

    # Достаточное условие сходимости
    print(f"f({a}) = {f_a}, f({b}) = {f_b}")
    print("f(a) и f(b) имеют разные знаки (f(a)*f(b) < 0). Функция непрерывна.")
    print("Следовательно, на интервале существует ровно один корень, и метод бисекции гарантированно сходится.")
    print("-------------------------------------------------------------------------------------------------------------------------------------------------")

    iterations = 0
    
    # Основной цикл метода половинного деления
    while (b - a) / 2 > tol:
        iterations += 1
        c = (a + b) / 2
        f_c = f(c)

        # Если нашли точный корень
        if f_c == 0:
            return c, f_c, iterations

        if f_a * f_c < 0:
            b = c
            f_b = f_c # Обновляем f_b для следующей итерации
        else: # f_b * f_c < 0
            a = c
            f_a = f_c # Обновляем f_a для следующей итерации
        
        # print(f"Итерация {iterations}: a={a:.6f}, b={b:.6f}, c={c:.6f}, f(c)={f_c:.6f}") # Отладочный вывод

    # Корень находится в середине конечного интервала
    root = (a + b) / 2
    return root, f(root), iterations

# --- Входные данные ---
interval_a = -10.0
interval_b = 10.0
initial_guess = 0.0 # Не используется методом бисекции напрямую
tolerance = 0.0001

# --- Выполнение ---
result = bisection_method(interval_a, interval_b, tolerance)

if result:
    found_root, value_at_root, num_iterations = result
    print("\n-------------------------------------------------------------------------------------------------------------------------------------------------")
    print(f"Найденный корень уравнения: {found_root:.{len(str(tolerance))-2}f}")
    print(f"Значение функции в корне f({found_root:.{len(str(tolerance))-2}f}): {value_at_root:.10f}")
    print(f"Число итераций: {num_iterations}")
    print("-------------------------------------------------------------------------------------------------------------------------------------------------")
```

### Объяснение работы кода:

1.  **`f(x)` функция:** Определяет наше уравнение `cos(x) - x`.
2.  **`bisection_method(a, b, tol)` функция:**
    *   Принимает границы интервала `a`, `b` и погрешность `tol`.
    *   **Предварительная проверка корней:**
        *   Вычисляет `f(a)` и `f(b)`.
        *   Проверяет, являются ли `a` или `b` точными корнями.
        *   **Проверяет условие `f(a) * f(b) > 0`:** Если оно истинно, то, исходя из монотонности функции `f(x)`, на интервале корней нет, и программа выводит сообщение и завершает работу.
        *   **Проверяет условие `f(a) * f(b) < 0`:** Если оно истинно, выводится сообщение о выполнении условий сходимости (непрерывность и разные знаки на концах интервала) и подтверждается наличие ровно одного корня.
    *   **Итерационный процесс:**
        *   Цикл `while (b - a) / 2 > tol` продолжается до тех пор, пока длина текущего интервала `[a, b]`, деленная пополам (максимальная возможная ошибка), не станет меньше заданной погрешности `tol`.
        *   На каждой итерации вычисляется середина `c` интервала `[a, b]` и значение `f(c)`.
        *   Если `f(c)` равно нулю, найден точный корень, и процесс завершается.
        *   В противном случае интервал сужается: если `f(a)` и `f(c)` имеют разные знаки, новый интервал становится `[a, c]`; иначе – `[c, b]`.
        *   Счетчик `iterations` увеличивается.
    *   По окончании цикла возвращается середина последнего интервала как приближенный корень, значение функции в нем и количество итераций.
3.  **Выполнение:**
    *   Устанавливаются начальные значения: интервал `[-10.0, 10.0]`, погрешность `0.0001`.
    *   Вызывается функция `bisection_method`.
    *   Результат выводится в консоль, включая найденный корень, значение функции в корне (которое должно быть близко к нулю) и число итераций.
